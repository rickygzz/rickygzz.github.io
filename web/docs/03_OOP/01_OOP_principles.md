# Object Oriented Programming Principles

## Encapsulation

This means keeping data (variables) and code (methods) inside one object. It hides the internal parts and only shows what is necessary. This protects the data and makes the object easier to use and understand.

## Abstraction

Means showing only the important details and hiding the complex parts. It lets you use objects without needed to know everything about how they work inside.

## Inheritance

Allows one class to get features from another. A child class can reuse code from a parent class. This saves tiem and helps organize code in a clean and logical way.

## Polymorphism

Lets the same action work in different ways. For example, the same method name can do different things depending on which object is using it. This makes code more flexible and reusable.<>
