# Composition

In programming, composition means that instead of inheriting from a base class, your class contains objects that bring in the functionality you need.

Composition offers flexibility and modularity. With inheritance, you get locked into a parent-child relationship, and any changes to the parent class might force unwanted behavior on child classes. On the other hand, composition is like a puzzle — you can replace any piece without messing up the entire structure.


## Differences

* Inheritance: Creates a rigid hierarchy. You’re saying, “A car is a type of vehicle,” which means a car inherits everything from the vehicle class, even things that might not apply.

* Composition: Assembles a class from smaller components. Instead of inheriting a vehicle’s properties, a car is built from an engine, wheels, and a steering wheel. This modular approach gives you more freedom and control.
